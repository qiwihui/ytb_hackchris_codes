# EIP-7702 与 ERC-4337

7702 让已有 EOA 指向执行代码；4337 提供用户操作及执行基础设施。两者可以组合，委托代码可实现兼容 4337 的路径。

本项目用普通交易与最小 relayer 展示授权、执行、付费分工，不证明 4337 过时。选择方案应考虑产品打包、恢复、付费和模块化需求。

签名显示取决于钱包实现和设备支持，不能从“用了 7702”推导硬件钱包必然显示结构化字段。本项目没有实现标准 EIP-712 签名界面。

依据：https://eips.ethereum.org/EIPS/eip-7702#forward-compatibility-with-future-account-abstraction
