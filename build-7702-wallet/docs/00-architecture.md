# 00. 架构

```
                        ┌─────────────────────────────┐
                        │   EOADelegate（逻辑合约）    │
                        │   只部署一次，所有委托的 EOA │
                        │   共享这一份运行时代码       │
                        └──────────────┬──────────────┘
                                       │ 委托目标
                                       │   （delegate 地址）
                                       ▼
        ┌────────────┐ 0x04 类型 4 tx  ┌──────────────────────────────┐
        │  EOA `U`   │ ──────────────▶ │ EOA U （code = 0xef0100||D） │
        │  持私钥    │                  │ 存储仍在 U 的地址下          │
        └────────────┘                  └──────────────┬───────────────┘
                                                       │
                  ┌────────────────────────┬───────────┴───────┬────────────────────────┐
                  │                        │                   │                        │
                  ▼                        ▼                   ▼                        ▼
     直接调用：U 调自己            代付：任何人提交        会话密钥：短期子        撤销：U 签一笔指向
     （execute / executeBatch）    U 签好的负载            密钥，绑定单个         零地址的授权，code
     msg.sender == address(this)   （executeWithSig）      target + 有效期        回到 0x
```

### 三个角色

| 角色 | 做什么 | 持有私钥 |
|------|--------|----------|
| **用户 EOA** | 签 7702 授权（往自己地址装委托代码）；签 个人消息（非 EIP-712） `Execute` 结构体 | 主私钥 |
| **委托合约** | 用户 EOA 把 code 指向它的运行时；提供 `execute` / `executeBatch` / `executeWithSig` / 会话密钥 | 无（它只是代码） |
| **Relayer / 代付方** | 持有 ETH，广播外层 tx，付 gas。**没有用户签名时动不了用户资金** | 代付方私钥（只花自己的 ETH） |

### 7702 相对于传统 EOA 改了什么

7702 之前：`eth_getCode(EOA) == 0x` 永远成立；EOA 不能有代码；想要批量化 / 代付 / 会话密钥的"智能钱包"体验必须部署新合约、迁移资金。

7702 之后：`eth_getCode(EOA) == 0xef0100 || delegate`；**EOA 地址不变**、**私钥照旧能用**，但 EOA 多出来一组合约入口。**没有迁移、没有新地址**——这就是 7702 全部的卖点。

### 这个 repo **不**涉及

- ERC-4337 的 EntryPoint / Bundler / Paymaster。我们在
  [`deep-dive/7702-vs-4337.md`](../deep-dive/7702-vs-4337.md) 里有文字对比，但**不写一行 4337 代码**——视频的立场是"你不需要 4337 也能让 EOA 拿到批量化、代付、会话密钥"。
- L2 特定行为（BLS pre-confirmation 等）。合约目标是主网，`evm_version = "prague"`。
